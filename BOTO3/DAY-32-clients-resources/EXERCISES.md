# Day 32 Exercises

## Objective
Practice clients and resources.

## Main task
Compare a client call with the resource interface for EC2.

## Safety
Use a dedicated learning account/profile where possible. Keep operations read-only. Never paste credentials into code, logs or reports.

## Required
- Accept profile/region from configuration or CLI.
- Handle expected AWS errors.
- Use pagination where supported.
- Produce structured output.

## Challenge
Turn the script into a reusable function with tests for the transformation logic.

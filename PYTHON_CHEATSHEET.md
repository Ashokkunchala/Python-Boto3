# Python Beginner Cheat Sheet

## Variables
```python
name = "Ashok"
age = 30
active = True
```

## Conditions
```python
if age >= 18:
    print("adult")
else:
    print("minor")
```

## Loops
```python
for item in ["ec2", "s3"]:
    print(item)
```

## Function
```python
def add(a, b):
    return a + b
```

## Dictionary
```python
server = {"name": "web-01", "state": "running"}
print(server["state"])
```

## Exception
```python
try:
    value = int("abc")
except ValueError:
    print("invalid number")
```

## DevOps connection
Python will later be used for files, APIs, subprocesses, JSON/YAML, AWS SDK calls, inventory, reporting, health checks and automation.

# Learning Gates

## Gate 1 — Python basics
Pass when you can write variables, conditions, loops, functions and collections without copying.

## Gate 2 — Python automation
Pass when you can read/write files, JSON/CSV, use argparse, logging, exceptions and subprocess safely.

## Gate 3 — Intermediate Python
Pass when you can write classes, type hints and pytest tests and explain when not to use them.

## Gate 4 — Boto3
Pass when you can create a session, select a region, paginate results, handle ClientError and produce a report.

## Gate 5 — AWS automation
Pass when your tool is tested, logged, safe by default, configurable and understandable by another engineer.

Do not advance only because the calendar says so. Repeat a day when you cannot explain or reproduce the work.

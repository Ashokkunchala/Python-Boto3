# Project 4 — EC2 Inventory

Build a read-only EC2 inventory tool.

Required fields:
- Account ID
- Region
- Instance ID
- Name tag
- Instance type
- State
- Private IP
- Availability Zone

Requirements:
- Use paginators.
- Add structured logging.
- Export JSON and CSV.
- Support one region first, then multiple regions.
- Add unit tests for transformation logic.

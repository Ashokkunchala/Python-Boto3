# START HERE — Python + Boto3

## You do not need to know Python
This course starts from zero. Do not start with Boto3. First learn Python, then automation, then AWS SDK usage.

## 60-day path
| Phase | Days | Goal |
|---|---:|---|
| Python Foundations | 1–20 | Learn Python from zero |
| Python Automation | 21–30 | Build useful scripts |
| Intermediate Python | 31–40 | Write maintainable code |
| Boto3 Fundamentals | 41–50 | Learn AWS SDK safely |
| AWS Automation | 51–60 | Build AWS automation projects |

## Daily method
1. Read the lesson.
2. Type every example yourself.
3. Solve exercises without copying solutions.
4. Run the mini challenge.
5. Check the completion checklist.

Existing production Boto3 material is intentionally kept for the later track. You do not need to understand it now.

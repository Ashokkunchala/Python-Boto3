# Python + Boto3 Roadmap

## Phase 1 — Python for automation

Functions, modules, packages, typing, dataclasses, exceptions, logging, argparse, JSON/CSV and testing.

## Phase 2 — Boto3 core

Sessions, profiles, regions, clients, resources, paginators, waiters, botocore Config and ClientError.

## Phase 3 — AWS automation

EC2, VPC, S3, IAM, RDS, DynamoDB, Lambda, SQS, CloudWatch and Organizations.

## Phase 4 — Production engineering

Idempotency, dry-run, retries, timeouts, throttling control, structured audit logs, least privilege, multi-account and multi-region scanning.

## Phase 5 — Capstone

Build an account inventory/compliance scanner that produces JSON and CSV, handles partial failures, and is fully unit tested.

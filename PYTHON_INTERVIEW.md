# Python Interview Questions — Beginner to DevOps

1. What is a variable? A name referencing a value.
2. List vs tuple? Lists are mutable; tuples are immutable.
3. What is a dictionary? A key-value mapping.
4. What is a function? Reusable code that can accept inputs and return a result.
5. Why use exceptions? To handle expected runtime failures without uncontrolled termination.
6. What is a module? A Python file that can be imported.
7. What is a virtual environment? An isolated Python package environment.
8. Why use logging instead of print? Logging provides levels, timestamps and configurable output.
9. What is JSON? A common text format for structured data and APIs.
10. Why learn Python before Boto3? Boto3 is Python code; Python fundamentals are required to understand and safely debug AWS automation.

# Day 27 Exercises

## Objective
Practice decorators and context managers.

## Main task
Write a timing decorator and use a context manager for a file.

## Requirements
1. Implement the task from scratch.
2. Add a DevOps/AWS-oriented variation.
3. Include at least one failure case or edge case.
4. Add tests when today's topic includes testing.

## Challenge
Make the result reusable by another engineer.

## Review
- [ ] Code is readable
- [ ] Names are meaningful
- [ ] Edge case considered
- [ ] Tests added where appropriate
- [ ] I can explain the design

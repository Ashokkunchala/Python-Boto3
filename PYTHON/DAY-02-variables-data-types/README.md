# Day 2 — Variables and Data Types

## Learn
Python commonly uses strings, integers, floats and booleans.

```python
name = "Ashok"
age = 30
height = 168.5
learning = True
print(type(name))
print(type(age))
print(type(height))
print(type(learning))
```

## Input
```python
name = input("Enter your name: ")
print("Hello", name)
```

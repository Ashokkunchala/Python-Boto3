# Day 01 Exercises

## Objective
Practice print(), variables.

## Tasks
1. Write a profile program.
2. Write the solution without copying the answer.
3. Add one DevOps/AWS variation.
4. Explain your code line by line.

## Challenge
Create a small script that uses today's topic to process realistic DevOps data.

## Review
- Does it run?
- Can you explain every line?
- What input can break it?
- How would you test it?

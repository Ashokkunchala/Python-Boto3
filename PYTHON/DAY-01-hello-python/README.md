# Day 1 — Hello Python

## Goal
Understand what Python is, how to run a program, variables at a basic level, and `print()`.

## First program
```python
print("Hello, Python!")
print("I am learning Python for AWS DevOps automation.")
```
Run: `python hello.py`

## Your first values
```python
name = "Ashok"
age = 30
print(name)
print(age)
```
A variable is a name that refers to a value.

## Exercises
1. Print your name.
2. Print your target role.
3. Store your city in a variable and print it.
4. Store a number in a variable and print it.

## Mini challenge
Print your name, role, city and one reason you want to learn Python.

## DevOps connection
Python will eventually automate AWS resources, files, commands, reports and CI/CD tasks.

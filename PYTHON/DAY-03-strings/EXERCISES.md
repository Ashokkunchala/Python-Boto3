# Day 03 Exercises

## Objective
Practice strings.

## Tasks
1. Parse an AWS-style name into service and environment.
2. Write the solution without copying.
3. Add one AWS/DevOps variation.
4. Explain every line.

## Challenge
Build a small script that processes realistic DevOps data using today's concept.

## Review checklist
- [ ] It runs.
- [ ] I can explain it.
- [ ] I handled invalid input where relevant.
- [ ] I can describe how I would test it.

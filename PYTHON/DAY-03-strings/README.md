# Day 3 — Strings

## Learn
Strings contain text.

```python
service = "EC2"
print(service.lower())
print(service.upper())
print(len(service))
```

## f-strings
```python
name = "web-01"
state = "running"
print(f"{name} is {state}")
```

## Exercises

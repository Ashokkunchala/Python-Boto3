# Day 05 — Tuples and Sets

## Goal
Tuples are ordered and immutable; sets store unique values.

## Example
```python
server = ("web-01", "running")
regions = {"us-east-1", "ap-south-1"}
```

## Exercises
Create a tuple for a server; create a set of unique regions; test membership.

## Mini challenge
Create a unique AWS-region list from repeated input.

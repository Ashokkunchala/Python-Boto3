# Lesson Standard

Every learning day follows this sequence:

1. Goal
2. Simple explanation
3. Example code
4. Exercises
5. Mini challenge
6. DevOps connection
7. Completion checklist

For the first learning pass, write code yourself before looking at the existing production package.

## Solution policy

Solutions should be used for review after an attempt, not copied before solving. Production Boto3 examples under `src/` are reference implementations for later study.

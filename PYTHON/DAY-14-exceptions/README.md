# Day 14 — Exceptions

## Goal
Handle expected failures with try/except.

## Example
```python
try:
    value = int(text)
except ValueError:
    print("invalid")
```

## Exercises
Handle missing files; invalid numbers; controlled fallback.

## Mini challenge
Build a resilient input parser.

## DevOps connection
Automation must fail clearly and safely.
